# Hebrew PDF font

`NotoSerifHebrew.ttf` is the Noto Serif Hebrew variable font from Google Fonts:

https://github.com/google/fonts/blob/main/ofl/notoserifhebrew/NotoSerifHebrew%5Bwdth%2Cwght%5D.ttf

Bundled under the accompanying SIL Open Font License (`OFL.txt`). The PDF renderer embeds the font directly, preserving Hebrew shaping and niqqud without a runtime network request.
