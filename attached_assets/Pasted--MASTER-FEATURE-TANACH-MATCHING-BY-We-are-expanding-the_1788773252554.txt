# MASTER FEATURE — TANACH MATCHING BY ראשי תיבות + סופי תיבות

We are expanding the existing Tanach discovery section on the Calculator.

The current Tanach feature already finds where the CURRENT FULL GEMATRIA appears in Tanach.

Keep that functionality exactly intact.

Now add TWO additional Tanach discovery methods:

1. ראשי תיבות
2. סופי תיבות

This is a substantial search feature. Inspect the existing Tanach search architecture carefully before changing anything.

IMPORTANT:
- production app is actively used
- preserve all existing data
- do not rewrite Tanach corpus
- do not reset/reseed database
- do not weaken existing whole-word matching rules
- partial-word matches must remain excluded from "הכל"

==================================================
1. CORE CONCEPT
==================================================

For the COMPLETE current calculator input:

derive:

A. ראשי תיבות
= first Hebrew letter of every word

B. סופי תיבות
= last Hebrew letter of every word

Example:

Input:
שמע ישראל

ראשי תיבות:
שי

סופי תיבות:
על

Then search the Tanach for contiguous COMPLETE-WORD sequences whose:

- ראשי תיבות exactly equal שי
OR
- סופי תיבות exactly equal על

These are separate match types.

==================================================
2. THIS IS EXACT LETTER MATCHING
==================================================

This feature is NOT:

- gematria-of-roshai-teivos numeric matching
- approximate matching
- partial-letter matching
- substring matching
- unordered matching

It is exact ראשי/סופי תיבות sequence matching.

Example:

Current ראשי תיבות:
שי

Valid candidate:

שמע ישראל
→ ש + י
→ שי

Another Tanach phrase of two complete words beginning:

ש... י...

is also a valid ראשי תיבות match.

But:

י... ש...

is NOT valid.

Order must match exactly.

==================================================
3. WORD COUNT MUST MATCH
==================================================

Every word contributes exactly one letter.

Therefore the candidate Tanach span must contain the same number of words as the current input.

Example:

Input:
שמע ישראל

2 words.

Search only contiguous 2-word Tanach spans for:

ראשי תיבות שי

and:

סופי תיבות על

Do not match a 3-word phrase merely because some letters happen to fit.

==================================================
4. CONTIGUOUS COMPLETE WORDS ONLY
==================================================

Use complete Hebrew words only.

Candidate words must:

- occur contiguously
- remain in canonical Tanach order
- belong to one verse
- never cross verse boundaries

Never use:

- partial words
- characters inside words
- suffix substrings
- prefix substrings
- skipped words
- reordered words

This must follow the same strict whole-word philosophy we just established for the existing Tanach search.

==================================================
5. NORMALIZATION
==================================================

Reuse the app's existing Hebrew normalization utilities wherever possible.

For deriving ראשי/סופי תיבות:

ignore:

- niqqud
- cantillation
- punctuation
- maqaf/punctuation separators according to the existing tokenizer
- non-Hebrew characters

Use actual Hebrew letters.

For comparison of final forms, normalize consistently so:

ך / כ
ם / מ
ן / נ
ף / פ
ץ / צ

do not cause false mismatches merely because of typing/canonical representation.

However:

preserve the correct original Tanach spelling for DISPLAY.

Do not visually replace final letters in the verse text.

==================================================
6. MINIMUM INPUT
==================================================

ראשי תיבות and סופי תיבות Tanach discovery should normally require at least TWO words.

For a one-word calculator input, do NOT search every Tanach word beginning or ending in one letter because that creates enormous low-value result sets.

If the current input contains fewer than 2 valid Hebrew words:

ראשי תיבות / סופי תיבות results should be unavailable or show a quiet message such as:

נדרשות לפחות שתי מילים

The normal full-gematria Tanach search must continue to work normally.
