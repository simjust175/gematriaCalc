THE GEMATRIA CURSOR — CORE FEATURE

THIS IS THE MOST IMPORTANT NEW INTERACTION.

The verse contains an interactive cursor.

The user can move through countable Hebrew letters.

As the cursor advances, the application calculates the running gematria from the START of the selected range through the CURRENT LETTER.

Example concept:

Cursor position 1:

ב

Running gematria:

2

Move forward through the word:

בראשית

1116

etc.

The calculation must update instantly.
