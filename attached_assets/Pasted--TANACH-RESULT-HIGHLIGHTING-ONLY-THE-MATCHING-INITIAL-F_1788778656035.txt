# TANACH RESULT HIGHLIGHTING — ONLY THE MATCHING INITIAL/FINAL LETTERS

The ראשי תיבות / סופי תיבות Tanach search logic is now correct.

This task is ONLY to refine how matching results are highlighted.

CURRENT PROBLEM:

In Tanach result cards, the entire matched words/phrase are currently receiving the gold background.

That is too visually heavy and does not clearly show WHY the result matched.

==================================================
REQUIRED BEHAVIOR
==================================================

For ראשי תיבות results:

highlight ONLY the FIRST matching Hebrew letter of each matched word.

Example pattern:

שבמ

Matched phrase:

שמע בני מוסר

Display conceptually as:

[ש]מע [ב]ני [מ]וסר

Only:

ש
ב
מ

should have the existing restrained gold background.

The rest of each word should remain normal text.

==================================================
סופי תיבות
==================================================

For סופי תיבות results:

highlight ONLY the FINAL matching Hebrew letter of each matched word.

Example:

word1 → final matching letter highlighted
word2 → final matching letter highlighted
word3 → final matching letter highlighted

Do NOT highlight the entire words.

==================================================
IMPORTANT
==================================================

Preserve:

- original Tanach spelling
- original maqaf
- niqqud/cantillation display
- punctuation
- verse context
- card layout
- reader links
- save-range behavior

Only change the visual highlight spans.

==================================================
FINAL LETTER FORMS
==================================================

If a סופי תיבות pattern matches via normalized final forms:

כ ↔ ך
מ ↔ ם
נ ↔ ן
פ ↔ ף
צ ↔ ץ

highlight the ACTUAL displayed final-form character from the Tanach text.

Example:

pattern:
מ

word ends:
ם

Then highlight:

ם

Do not visually replace it with מ.

==================================================
MAQAF
==================================================

If a phrase contains:

בית־אל

and it is treated internally as two logical words:

preserve the displayed:

בית־אל

If ראשי תיבות matches both logical words:

highlight only:

ב in בית
א in אל

Do NOT highlight the maqaf.
