# TANACH NAVIGATION — ספר → פרשה / פרק → פסוק

We need to improve the existing Tanach result navigation.

The current filtering works, but there are two problems:

1. The first filter is based around חומש, which does not fit the entire תנ״ך.
2. The current dropdown menus use browser-native `<select>` styling and look visually cheap/inconsistent with the rest of the application.

This task should solve BOTH.

## CRITICAL

Do NOT change:

* gematria calculations
* Tanach match detection
* match highlighting
* result cards
* result categories
* result sorting
* saved calculations
* calculator
* existing פרשת השבוע button design or behavior
* overall cream / navy / gold visual language

The existing **פרשת השבוע** button should remain exactly as it is.

* בראשית
* שמות

Use the application's established 24-book canonical display structure and translate that safely to the underlying Tanach data.
